# Structure du Projet MiniGénie

## Organisation des Documents

```
MiniGenie/
├── .cursorrules              # Configuration de l'agent IA (déjà créé)
├── DEVELOPMENT_PROMPT.md     # Votre prompt principal de développement
├── PROJECT_STRUCTURE.md      # Ce fichier (guide d'organisation)
│
├── docs/                     # Documentation du projet
│   ├── README.md
│   ├── documents_techniques/
│   ├── documents_fonctionnels/
│   ├── documents_design/
│   └── documents_reference/
│
├── specs/                    # Spécifications détaillées
│   ├── README.md
│   ├── PROJECT_SPEC.md
│   ├── FEATURES.md
│   └── REQUIREMENTS.md
│
└── rules/                    # Règles de développement
    ├── README.md
    ├── DEVELOPMENT_RULES.md
    └── PROJECT_RULES.md
```

## Comment Procéder

1. **Placez vos documents** dans les dossiers appropriés :
   - Documentation → `docs/`
   - Spécifications → `specs/`
   - Règles → `rules/`

2. **Votre prompt principal** → `DEVELOPMENT_PROMPT.md`

3. **Je lirai tout** avant de commencer le développement

## Avantages

- ✅ Organisation claire et structurée
- ✅ Je peux facilement trouver et lire tous les documents
- ✅ Séparation logique entre docs, specs et rules
- ✅ Facilite la maintenance et les mises à jour
