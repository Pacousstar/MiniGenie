# 🔧 Configuration Environnement - Dashboard Web

## 📋 Variables d'Environnement

Créez un fichier `.env.local` dans `apps/web/` avec :

```env
# URL de l'API backend
NEXT_PUBLIC_API_URL=http://localhost:3001
```

## 📝 Notes

- Le fichier `.env.local` est ignoré par Git (sécurité)
- En production, utilisez les variables d'environnement de votre hébergeur
- Par défaut, l'API est sur `http://localhost:3001`
