# 🎵 Recommandations de Sites pour les Sons

## 📋 Sites Recommandés pour Télécharger des Sons Gratuits

### 1. **Freesound.org** ⭐⭐⭐⭐⭐
- **URL** : https://freesound.org
- **Avantages** :
  - Base de données énorme (millions de sons)
  - Gratuit avec compte (inscription rapide)
  - Licence Creative Commons
  - Recherche par tags (success, error, celebration, etc.)
  - Qualité variable mais généralement bonne
- **Recherches suggérées** :
  - "success sound" ou "ding"
  - "error sound" ou "wrong"
  - "celebration" ou "fanfare"
  - "badge unlock" ou "achievement"
  - "click" ou "button click"
  - "encouragement" ou "positive"

### 2. **Zapsplat.com** ⭐⭐⭐⭐

## 🎯 Sons Spécifiques à Rechercher

### Son de Succès (success.mp3)
- **Tags de recherche** : "success", "ding", "correct", "right answer", "positive", "chime"
- **Caractéristiques** : Court (200-300ms), montant, joyeux
- **Exemples** : "ding-ding", "bell chime", "success chime"

### Son d'Erreur (error.mp3)
- **Tags de recherche** : "error", "wrong", "incorrect", "soft error", "gentle wrong"
- **Caractéristiques** : Court (200-300ms), descendant doux, pas punitif
- **Exemples** : "soft buzz", "gentle error", "wrong answer soft"

### Son de Badge (badge.mp3)
- **Tags de recherche** : "achievement", "badge", "unlock", "level up", "reward"
- **Caractéristiques** : Moyen (300-500ms), séquence montante
- **Exemples** : "achievement unlock", "level up sound", "reward chime"

### Son de Célébration (celebration.mp3)
- **Tags de recherche** : "celebration", "fanfare", "victory", "success fanfare", "triumph"
- **Caractéristiques** : Long (1-2s), joyeux, énergique
- **Exemples** : "victory fanfare", "celebration sound", "success fanfare"

### Son de Clic (click.mp3)
- **Tags de recherche** : "click", "button click", "tap", "ui click", "interface click"
- **Caractéristiques** : Très court (50-100ms), discret
- **Exemples** : "ui click", "button tap", "interface click"

### Son d'Encouragement (encouragement.mp3)
- **Tags de recherche** : "encouragement", "positive", "uplifting", "motivational", "cheerful"
- **Caractéristiques** : Court-moyen (300-400ms), positif
- **Exemples** : "positive chime", "encouragement sound", "uplifting tone"

## 📝 Instructions de Téléchargement

1. **Créer le dossier** :
   ```
   apps/mobile/assets/sounds/
   ```

2. **Télécharger les fichiers** :
   - Format : MP3 (recommandé) ou WAV
   - Nommer les fichiers exactement :
     - `success.mp3`
     - `error.mp3`
     - `badge.mp3`
     - `celebration.mp3`
     - `click.mp3`
     - `encouragement.mp3`

3. **Optimiser les fichiers** (optionnel mais recommandé) :
   - Durée : Respecter les durées recommandées
   - Volume : Normaliser à -3dB
   - Format : MP3 128kbps minimum
   - Fréquence : 44.1kHz

4. **Tester** : Une fois les fichiers ajoutés, le service SoundService fonctionnera automatiquement.

## 🔧 Alternative : Sons Système

Si vous ne trouvez pas de fichiers audio, vous pouvez aussi :
- Utiliser des sons système iOS/Android (mais moins personnalisés)
- Générer des sons avec des outils en ligne (Online Tone Generator, etc.)
- Utiliser des bibliothèques de sons pré-packagées pour React Native

## ⚠️ Important - Licences

- Vérifier toujours la licence avant d'utiliser un son
- Pour MiniGénie (usage commercial potentiel), privilégier :
  - Creative Commons 0 (CC0) - Domaine public
  - Creative Commons Attribution (CC BY) - Avec attribution
  - Licences libres d'utilisation commerciale
