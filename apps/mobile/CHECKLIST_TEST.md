# ✅ Checklist de Test Rapide

## 🚀 Avant de commencer

- [ ] Node.js installé (v18+)
- [ ] Expo CLI installé : `npm install -g expo-cli`
- [ ] Expo Go installé sur téléphone
- [ ] Dépendances installées : `npm install`
- [ ] Sons générés : `node scripts/generateSounds.js`

---

## 📱 Tests de base

### Écran d'accueil
- [ ] Application démarre sans erreur
- [ ] Assena visible et animé
- [ ] 8 modules affichés
- [ ] Navigation vers modules fonctionne

### Module Alphabet
- [ ] Lettres A-Z affichées
- [ ] TTS prononce lettres et exemples
- [ ] Navigation fluide
- [ ] Animations fluides

### Module Chiffres
- [ ] Chiffres 1-100 affichés
- [ ] Représentation visuelle adaptée
- [ ] TTS fonctionne
- [ ] Navigation fluide

### Module Calcul
- [ ] Questions variées (additions, soustractions, comparaisons)
- [ ] Sons de succès/erreur joués
- [ ] Feedback visuel fonctionne
- [ ] Score mis à jour

### Module Écriture
- [ ] 52 lettres disponibles (majuscules + minuscules)
- [ ] Tracé fonctionne
- [ ] Guide pulsant visible
- [ ] Feedback après tracé

### Module Vocabulaire
- [ ] 200+ mots disponibles
- [ ] Toutes les catégories présentes
- [ ] Horloges affichées pour les heures
- [ ] TTS adapté pour heures

### Module Syllabes
- [ ] 100+ syllabes disponibles
- [ ] TTS prononce chaque syllabe
- [ ] Navigation fluide

### Module Lecture
- [ ] 50+ items (mots et phrases)
- [ ] Bouton "Voir la réponse" fonctionne
- [ ] TTS adapté

### Module Famille
- [ ] 20+ membres de famille
- [ ] Descriptions présentes
- [ ] TTS fonctionne

---

## 🔊 Tests des sons

- [ ] Son de succès joué (Calcul - bonne réponse)
- [ ] Son d'erreur joué (Calcul - mauvaise réponse)
- [ ] Son de badge joué (fin de module)
- [ ] Son de célébration joué (badge débloqué)
- [ ] Son d'encouragement joué (Écriture)

---

## 🎨 Tests des animations

- [ ] Assena change d'expression
- [ ] Transitions entre écrans fluides
- [ ] Animations dans modules fluides
- [ ] Célébration de badge animée
- [ ] Pas de lag ou freeze

---

## ⚡ Tests de performance

- [ ] Temps de chargement < 2 secondes
- [ ] Transitions < 300ms
- [ ] Pas de freeze
- [ ] Pas de crash
- [ ] Navigation rapide fonctionne

---

## 🐛 Tests d'erreurs

- [ ] Application fonctionne offline
- [ ] Pas de crash avec erreurs TTS
- [ ] Pas de crash avec erreurs audio
- [ ] Messages d'erreur appropriés
