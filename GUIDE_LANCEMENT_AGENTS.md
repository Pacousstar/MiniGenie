## 📋 Comment Lancer les Agents

### Étape 1 : Lancer Agent 3 (Mobile & Modules)

1. **Ouvrez une nouvelle conversation** dans Cursor (bouton "New Chat" ou `Ctrl+L`)

2. **Copiez-collez ce message initial** :

```
Je suis Agent 3 pour MiniGénie - Développement Mobile & Modules Pédagogiques.

Lis ces fichiers pour comprendre le contexte :
- @PLAN_REPARTITION_AGENTS.md (plan de répartition)
- @AGENT3_TACHES.md (mes tâches)
- @DEVELOPMENT_PROMPT.md (prompt principal)
- @docs/README.md (documentation)
- @specs/README.md (spécifications)
- @rules/README.md (règles de code)
- @FONCTIONNALITES_COMPLETEES.md (ce qui est fait)
- @FONCTIONNALITES_MANQUANTES.md (ce qui manque)

Mon rôle : Développer et améliorer l'application mobile Expo et les modules pédagogiques.

Commence par lire AGENT3_TACHES.md et dis-moi quelle tâche tu veux commencer.
```

3. **Agent 3 va** :
   - Lire les fichiers de contexte
   - Voir ses tâches dans `AGENT3_TACHES.md`
   - Commencer à travailler
   - Mettre à jour `AGENT3_TACHES.md` après chaque étape
